# EducationCenter API

Учебный backend-проект для управления образовательным центром.

API позволяет работать со студентами, группами, преподавателями,
курсами и предметами.

## Стек

- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Swagger / OpenAPI
- xUnit
- EF Core InMemory для тестов

## Возможности

- CRUD для основных сущностей
- Связи one-to-many и many-to-many
- DTO для запросов и ответов
- Проверка связанных сущностей
- Корректные HTTP-статусы
- Добавление и удаление связей
- Автоматические тесты

## Основные сущности

- `Course` — учебный курс
- `Subject` — предмет
- `Teacher` — преподаватель
- `Group` — учебная группа
- `Student` — студент

Курсы связаны с предметами, преподаватели — с предметами, группы — с
курсами, преподавателями и предметами, а студенты могут состоять в группах.

## Запуск проекта

Перед запуском необходимо создать базу данных PostgreSQL и проверить строку
подключения `DefaultConnection` в `EducationCenter.Api/appsettings.json`.

```bash
dotnet ef database update --project EducationCenter.Api
dotnet run --project EducationCenter.Api
```

После получения новых миграций повторите `dotnet ef database update --project EducationCenter.Api`.
Миграция `RestrictCourseDeletion` запрещает удаление курса с группами на уровне
PostgreSQL. При конфликте удаления API возвращает `409 Conflict`, в том числе
если группа появилась между предварительной проверкой и удалением курса.

В режиме разработки Swagger UI доступен по адресу приложения, указанному в
`EducationCenter.Api/Properties/launchSettings.json`.

## Валидация запросов

Для POST и PUT действуют одинаковые правила:

- имена и названия обязательны и не могут состоять только из пробелов;
- цена курса должна быть неотрицательной, нулевая цена допустима;
- дата рождения обязательна и не может быть позже текущей даты UTC;
  значение `0001-01-01` считается незаданной датой.

Некорректные запросы возвращают `400 Bad Request` с описанием ошибок
по полям в формате `ValidationProblemDetails`.

## Тесты

Запустить все тесты решения можно командой:

```bash
dotnet test
```

Тесты проверяют основные операции контроллеров, работу связей, обработку
несуществующих внешних ID и защиту от удаления используемых сущностей.
HTTP-тесты дополнительно проверяют валидацию POST/PUT и отсутствие изменений
данных при отклонении запроса. В тестах используется EF Core InMemory.
